# Итоговый проект по анализу данных — Тестовое задание

## Описание проекта

В рамках итогового проекта выполнено тестовое задание по продуктовой аналитике, анализу пользовательской активности, A/B-тестированию и статистике.

Проект включает 18 вопросов, для решения которых использовались Python, Jupyter Notebook и Excel.

## Основные задачи

- Анализ пользовательской активности: DAU и MAU.
- Расчёт удержания пользователей (Retention).
- Анализ конверсии и просмотров рекламы.
- Расчёт NPS.
- Анализ доходов и характеристик пользователей.
- Проверка статистических гипотез.
- Анализ результатов A/B-тестирования.
- Интерпретация аналитических показателей.

## Используемые инструменты

- Python
- Jupyter Notebook
- Pandas
- NumPy
- SciPy
- Microsoft Excel

## Файлы проекта

- `Тестовое задание.docx` — ответы на 18 вопросов.
- `test_assignment.ipynb` — программные расчёты и статистический анализ.
- `Данные для тестового задания.xlsx` — исходные данные.

## Результаты

В ходе выполнения задания рассчитаны показатели пользовательской активности, удержания, конверсии, NPS и доходов. Проведены статистические проверки гипотез и сформулированы выводы по результатам анализа.
